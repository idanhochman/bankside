## Decisions made

- **R1:** MAC and MAD take the same 16 (src0, src1) pairs as MUL
  ([TOP-ISA-22]); the paper's 14/28 doesn't name the dropped pairs, ANEMOS
  accepts all 16. #6, PR #20.
- **R12:** MAD's SRC2 must be SRF_A, else illegal ([TOP-ISA-23]). #6, PR #20.
- **R2, R3:** ReLU is the paper's sign-bit mux (differs from ANEMOS on 1024 of
  65536 inputs); every NaN result is 0x7E00; MOV and FILL copy bits unchanged
  ([TOP-FP-8], [TOP-FP-6], [TOP-FP-9]). #7, PR #21.
- **R4, R5, R11:** register files stay unreset, a never-written entry reads its
  power-up value ([TOP-ARCH-9]); write-through at distance 3; GRF_B has 3 read
  ports. #8, PR #38.
- **R6 to R8:** an illegal word is a one-slot NOP with a sticky `err_illegal`;
  MOV GRF to SRF uses lane 0; each broken control rule has a defined outcome
  ([TOP-ISA-24] to [TOP-ISA-30]). #9, PR #36.
- **R9, R10:** every write is in S5, in program order; the v1 bank is a
  synchronous SRAM with a one-cycle read, write applied first on a same-edge
  store and read; `busy` timing is exact ([TOP-PIPE-1], [TOP-IF-2],
  [TOP-IF-7]). #10, PR #40.
- **MAC SRC2 (#19):** the assembler writes GRF_B (as the paper's Section III-C
  encodes it), the hardware ignores the field (option 3). The user's decision,
  relayed by the lead. #19, #29, PR #39.
- **Module split:** `top` has `pcu_ctrl` (with `pcu_decode`), `pcu_datapath`
  (16 `fp16_mul`, 16 `fp16_add`) and five `pcu_regfile` instances; shared
  package in `common`; no wrapper module in v1. #11, PR #28.
- **Zero-slot JUMP fetch:** `pcu_ctrl` reads the CRF twice in a cycle, chained
  (`N_RD` = 2). #27, PR #47.
- **Clock edge and first reset:** rising edge ([TOP-ARCH-11]); outputs are
  undefined up to the first reset cycle ([TOP-IF-13]). #44, #46, PR #60.
- **Where unit testplans go:** in the milestone of the module's RTL, so M2 for
  fp16_mul and fp16_add, M4 for the rest; common's package RTL and unit test
  in M4. The user's decisions, relayed by the lead. #51 (PR #52), #58 (PR #59).
